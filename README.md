# Olympiad

Репозиторий для олимпиадных заданий и их решений

Для успешной подачи решения необходимо:

1. Сделать форк репозитория (прям всего).
2. Сделать новую ветку `solution`.
3. Создать папку `solution`.
4. Создать файл `solution/participant.md`.
5. Созданый файл заполнить по образцу `participant.md`.
6. Разместить в папке `solution` решения, называя файлы решений так же, как они называются в папке `problems`, но с расширением `.py`. Например: `01_robot.py`.
7. Предложить PR оригинальному репозиторию.

Не четкое соблюдение формальных требований ведет к мгновенной дисквалификации!
