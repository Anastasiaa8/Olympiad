# A4. Раскраска ожерелья

**Тур:** онлайн-этап, заочный тур по программированию на Python
**Тип:** один тест на файл, проверка по выводу (stdin/stdout)
**Баллы:** 250 (50 + 80 + 120) · **Ограничение времени:** 2 с · **Память:** 256 МБ

## Легенда

На нитку нанизаны `n` бусин, расположенных по кругу (бусина `i` соседствует с
бусинами `i−1` и `i+1`, бусины `1` и `n` тоже соседи). Каждую бусину нужно
покрасить одним из `k` цветов так, чтобы **любые две соседние бусины были
разных цветов**.

Две раскраски считаются **одинаковыми**, если одна получается из другой
поворотом круга или переворачиванием ожерелья «на другую сторону» (отражением).
То есть ожерелье можно свободно вращать и переворачивать — учитываются все
`2n` способов его повернуть/отразить.

Нужно посчитать количество различных раскрасок ожерелья. Ответ выводится
**по модулю** `1000000007`.

## Формат ввода

Одна строка с двумя целыми числами `n` и `k`.

## Формат вывода

Одно целое число — количество различных раскрасок по модулю `1000000007`.

## Ограничения

- `3 ≤ n ≤ 10^9`;
- `1 ≤ k ≤ 10^9`.

## Подзадачи

| Подзадача | Баллы | Дополнительные ограничения |
| --- | --- | --- |
| A | 50 | `n ≤ 10`, `k ≤ 4` — перебор всех `k^n` раскрасок с нормализацией |
| B | 80 | `n ≤ 2000`, `k ≤ 2000` — перебор всех `2n` движений уже невозможен, нужно считать по классам |
| C | 120 | полные ограничения |

## Примеры

**Пример 1**

```
Ввод:
3 3
Вывод:
1
```

Из трёх бусин и трёх цветов все подходящие раскраски (три разных цвета)
переходят друг в друга поворотом и отражением — ожерелье ровно одно.

**Пример 2**

```
Ввод:
4 3
Вывод:
6
```

Подходящих покрасок четырёх бусин в три цвета — `18`, но они сливаются в `6`
ожерелий, и их легко перечислить руками:

- чередование двух цветов `A B A B` — выбор пары цветов из трёх: `3` шт.;
- противоположные бусины окрашены одинаково, остальные двумя цветами —
  `A B A C`: выбор «повторяющегося» цвета даёт ещё `3` шт.

Итого `6`. Обратите внимание: наивное «поделить `18` на `8`» не даёт ответа —
орбиты у раскрасок разного размера.

**Пример 3**

```
Ввод:
9 2
Вывод:
0
```

Нечётный цикл нельзя раскрасить в два цвета так, чтобы соседи различались, —
раскрасок нет вовсе.

**Пример 4**

```
Ввод:
10 3
Вывод:
78
```

**Пример 5**

```
Ввод:
720720 6
Вывод:
677262965
```

Здесь `720720 = 2^4 · 3^2 · 5 · 7 · 13` — у числа много делителей, и
перебирать все `n` поворотов нельзя.

## Примечания

- Отражения важны: если считать одинаковыми только повороты (обычные
  «нейколы-ориентированные»), ответ для того же теста будет другим.
- Для `k = 1` и `n ≥ 3` раскрасок нет.
- Ответ — точное число, делённое на `2n`; в модульной арифметике деление
  заменяется умножением на обратный элемент (модуль простой, а `2n` делит
  точное значение, а не остаток).
