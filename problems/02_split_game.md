# A2. Разделение кучек

**Тур:** онлайн-этап, заочный тур по программированию на Python
**Тип:** несколько тестов во входном файле, проверка по выводу (stdin/stdout)
**Баллы:** 150 (30 + 50 + 70) · **Ограничение времени:** 3 с · **Память:** 256 МБ

## Легенда

На столе стоят `n` кучек, в `i`-й кучке лежит `a_i` фишек. Играют двое,
ходит первый. Ход состоит в следующем: игрок выбирает одну кучку и делит её
на **две** непустые части. Если размеры частей — это числа `x` и `y`
(`x + y` равен размеру исходной кучки), то пусть `a = max(x, y)`,
`b = min(x, y)`. Разрешено только такое деление, для которого

```
a > b    и    a ≤ k · b
```

то есть части обязаны быть **разными**, но при этом **не слишком** разными.
Кучки, которые нельзя поделить законно, остаются нетронутыми.

Проигрывает тот, кто не может сделать ход (выигрывает сделавший последний
ход). Оба игрока играют оптимально.

Требуется для каждой позиции определить, выигрывает ли первый игрок, и если
да — **сколько различных выигрышных первых ходов** у него есть.

**Что считается ходом.** Ход полностью задаётся парой `(m, b)`: размер `m`
делимой кучки и меньший из полученных размеров `b`. Одинаковые кучки
неразличимы: если на столе стоят две кучки размера 5 и обе можно поделить
одинаково, то такой ход считается **одним**, а не двумя.

## Формат ввода

Первая строка — число тестов `t`. Далее для каждого теста:

- строка `n k`;
- строка из `n` целых чисел `a_1 … a_n` — размеры кучек.

## Формат вывода

Для каждого теста выведите одну строку:

- `Win c` — если первый игрок выигрывает, где `c` — число различных
  выигрышных первых ходов;
- `Lose 0` — если первый игрок проигрывает при оптимальной игре второго
  (в этом случае `c = 0`).

## Ограничения

- `1 ≤ t ≤ 5`;
- `1 ≤ n ≤ 50`;
- `1 ≤ a_i ≤ 3000`;
- `1 ≤ k ≤ 10^9`;
- суммарное число фишек в одном тесте не превосходит `150000`.

## Примеры

**Пример**

```
Ввод:
8
1 2
5
2 2
5 5
1 3
10
2 2
5 6
1 3
4
2 2
3 4
3 2
5 5 6
3 2
7 7 7
Вывод:
Lose 0
Lose 0
Lose 0
Win 2
Lose 0
Win 1
Win 2
Lose 0
```

Пояснения к некоторым тестам (`k = 2`, поэтому для частей `a > b` требуется
`a ≤ 2b`):

- Кучка `5`: единственное допустимое деление — `5 = 3 + 2` (`3 > 2` и
  `3 ≤ 4`). Затем из `3` можно получить `2 + 1`, а `2` делить нельзя.
  Одна кучка `5` — проигрышная позиция (`Lose 0`), это проверяется первым
  тестом.
- Тест `2 2 / 5 6`: кучка `6` допускает ровно одно деление — `6 = 4 + 2`
  (`4 ≤ 2·2`), кучка `5` — одно деление `5 = 3 + 2`. Позиция выигрышная,
  выигрышных первых хода два: разделить `5` или разделить `6` → `Win 2`.
- Тест `3 2 / 5 5 6`: две кучки по `5` неразличимы, поэтому ход «разделить
  кучку `5` как `3+2`» засчитывается один раз. Итого `Win 2`, а не `Win 3`.
- Тест `3 2 / 7 7 7`: позиция проигрышная → `Lose 0`.

## Примечания

- Случай `k = 1`: условие `a > b` и `a ≤ b` несовместимо, поэтому ни одна
  кучка делить нельзя — первый игрок всегда проигрывает.
- Не путайте игру с классической «Grundy's game» (там достаточно требовать `x ≠ y`):
  при `k ≥ 2` появляются дополнительные запреты, и значения Grundy для одной
  кучки не совпадают с табличными «из книг».
- Позиция из нескольких кучек — это дизъюнктивная сумма: нельзя рассуждать
  «выгодно ли делить большую кучку»; нужен корректный анализ всей позиции
  сразу.
