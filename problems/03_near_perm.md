# A3. Почти упорядоченные перестановки

**Тур:** онлайн-этап, заочный тур по программированию на Python
**Тип:** один тест на файл, проверка по выводу (stdin/stdout)
**Баллы:** 200 (40 + 60 + 100) · **Ограничение времени:** 3 с · **Память:** 256 МБ

## Легенда

Перестановка `π` длины `n` — это последовательность `π(1), π(2), …, π(n)`,
содержащая каждое число от `1` до `n` ровно один раз. Назовём перестановку
**почти упорядоченной** с параметром `k`, если каждая позиция стоит близко к
своему значению:

```
|π(i) − i| ≤ k    для всех i = 1 … n
```

Нужно посчитать количество почти упорядоченных перестановок длины `n` по
заданному `k`.

Число может быть огромным, поэтому ответ выводится **по модулю** `998244353`.

## Формат ввода

Одна строка с двумя целыми числами `n` и `k`.

## Формат вывода

Одно целое число — количество перестановок по модулю `998244353`.

## Ограничения

Во всех тестах:

- `1 ≤ n ≤ 200000`;
- `0 ≤ k ≤ 10^9`.

Дополнительные ограничения подзадач суммируются с этими.

## Подзадачи

| Подзадача | Баллы | Дополнительные ограничения |
| --- | --- | --- |
| A | 40 | `n ≤ 10` — допустим полный перебор всех `n!` перестановок |
| B | 60 | `k ≤ 2` |
| C | 100 | `k ≤ 4` и `n ≤ 20000` |

## Примеры

**Пример 1**

```
Ввод:
4 1
Вывод:
5
```

Это перестановки `1234`, `1243`, `1324`, `2134`, `2143`. Например, `1432`
не подходит: `|π(2) − 2| = |4 − 2| = 2 > 1`.

**Пример 2**

```
Ввод:
5 5
Вывод:
120
```

Если `k ≥ n − 1`, ограничение ни на что не влияет: подходят все `5! = 120`
перестановок.

**Пример 3**

```
Ввод:
8 2
Вывод:
400
```

**Пример 4**

```
Ввод:
200000 2
Вывод:
881430032
```

Настоящее значение велико, в выводе — остаток от деления на `998244353`.

## Примечания

- `k = 0` допустим: подходящая перестановка ровно одна.
- При `k = 1` ответ равен числам Фибоначчи (с подходящим сдвигом). Эту
  закономерность **нельзя** переносить на `k ≥ 2`.
- В задаче встречается `k`, превышающий `n`; перебирать «окно» размера `2k+1`
  при этом бессмысленно.
- Модуль `998244353` — простое число, но делить по модулю в этом задании не
  требуется.
