# A1. Робот с циклами

**Тур:** онлайн-этап, заочный тур по программированию на Python
**Тип:** один тест на файл, проверка по выводу (stdin/stdout)
**Баллы:** 100 (30 + 30 + 40) · **Ограничение времени:** 2 с · **Память:** 256 МБ

## Легенда

Робот стоит на клетчатой плоскости в точке `(0, 0)` и смотрит на **север**
(в сторону возрастающей координаты `y`; ось `x` направлена на восток).
Ему дают программу на мини-языке. Робот выполняет её команды строго по порядку,
после чего останавливается. Нужно узнать, в какой точке он окажется.

Алфавит программы:

| Символ | Действие |
| --- | --- |
| `F` | шаг **вперёд** в текущем направлении робота |
| `B` | шаг **назад** (против текущего направления) |
| `R` | шаг **вправо** — боковой шаг, направление робота **не** меняется |
| `L` | шаг **влево** — боковой шаг, направление робота **не** меняется |
| `)` | поворот на 90° **по** часовой стрелке (на месте) |
| `(` | поворот на 90° **против** часовой стрелки (на месте) |
| `N[<тело>]` | выполнить `<тело>` **ровно `N` раз подряд** |

Направления: север `→` `+y`, восток `+x`, юг `-y`, запад `-x`. Повороты
накапливаются: четыре `)` подряд возвращают робота исходным взглядом.

Цикл `N[<тело>]` означает обычное текстовое раскрытие: программа с циклом
ведёт себя ровно так, если бы вместо `N[X]` было записано `N` копий текста `<тело>`
подряд. Состояние робота между повторами **сохраняется** (и позиция, и направление).
Циклы могут быть вложенными, тело цикла может быть пустым (`0[]`, `5[()]` —
допустимые фрагменты), а цикл с `N = 0` просто ничего не делает.

Формально программа задаётся грамматикой:

```
<program>  ::= <statement>*
<statement> ::= <move> | '(' | ')' | <count> '[' <program> ']'
<move>     ::= 'F' | 'B' | 'L' | 'R'
<count>    ::= десятичная запись целого от 0 до 10^9 без ведущих нулей
               (единственный разрешённый ведущий ноль — само число 0)
```

Число читается **максимально длинной** последовательностью цифр: в `12[FR]`
тело `FR` выполняется 12 раз, а не «один раз `1`, потом два раза `FR`».

## Формат ввода

Одна строка — программа. Гарантируется корректность программы по грамматике выше.

## Формат вывода

Два целых числа через пробел — координаты `x` и `y`, где окажется робот.
Выводится точное значение, без модуля.

## Ограничения

- длина программы (в символах) ≤ 5000;
- глубина вложенности циклов ≤ 10;
- все счётчики ≤ 10^9;
- координаты итоговой позиции по модулю не превосходят 10^94 — обычным
  64-битным целым их не выразить (в Python это не проблема).

## Подзадачи

| Подзадача | Баллы | Дополнительные ограничения |
| --- | --- | --- |
| A | 30 | в программе нет ни цифр, ни скобок `[`/`]` (только `F`, `B`, `L`, `R`, `(`, `)`), длина ≤ 100 |
| B | 30 | длина ≤ 200, все счётчики ≤ 100, суммарная длина программы после полного раскрытия ≤ 10^4 |
| C | 40 | полные ограничения |

## Примеры

**Пример 1**

```
Ввод:
3[FR]
Вывод:
3 3
```

Тело `FR` — один шаг на север и один на восток, то есть `(x, y) += (1, 1)`;
цикл не поворачивает робота, поэтому тело раскрывается три раза как есть.

**Пример 2**

```
Ввод:
2[F)]
Вывод:
1 1
```

Первый повтор: `F` — шаг на север, `(0, 1)`; `)` — робот смотрит на восток.
Второй повтор: `F` — шаг на восток, `(1, 1)`; `)` — смотрит на юг. Итог `(1, 1)`.

**Пример 3**

```
Ввод:
)L3[B]F
Вывод:
-2 1
```

Разбор: `)` — робот смотрит на восток; `L` — боковой шаг влево, то есть на север,
`(0, 1)`; `3[B]` — три шага назад относительно текущего направления (на восток),
то есть `(-3, 0)`; `F` — шаг вперёд на восток, `(+1, 0)`. Итог `(-2, 1)`.

**Пример 4**

```
Ввод:
1000000000[F)]
Вывод:
0 0
```

Тело цикла поворачивает робота на 90°, поэтому четыре повтора образуют замкнутый
квадрат, а 10^9 кратно 4 — робот возвращается в исходную точку.
Раскрывать такой цикл «в лоб» нельзя: он соответствовал бы программе из
4·10^9 команд.

## Примечания

- Порядок команд внутри тела цикла важен: смещение тела нужно поворачивать
  на направление, в котором робот смотрит на входе в тело, и это направление
  меняется от повтора к повтору, если тело содержит повороты.
- Программа может быть длинной, а её полное раскрытие — недостижимо длинным,
  поэтому простое «выполнить по шагам» не проходит основную подзадачу.
